# منصة بصائر — نواة الخادم والفصول المباشرة

هذه النسخة تضيف بداية الخادم الآمن إلى ملفات الموقع الأصلية، دون تغيير تصميم الصفحة الرئيسية.

## الموجود في هذه الحزمة
- `index.html` والصور الأصلية كما هي.
- `server/`: خادم Node.js / Express.
- PostgreSQL لحفظ الحسابات وتخصيص الحلقات.
- LiveKit لإصدار رموز دخول قصيرة العمر.
- أدوار منفصلة: `admin` و`teacher` و`student`.
- لا يوجد تسجيل ذاتي عام؛ الإدارة تنشئ حسابات المحاضرين والطلاب.
- الطالب يخصص لحلقة واحدة فقط، والمحاضر للحلقات التي تسمح بها الإدارة.
- مفاتيح LiveKit لا تُرسل إلى المتصفح.

## الحلقات المعرفة
- `quran` — تحفيظ القرآن
- `tajweed` — التجويد والتلاوة
- `sharia` — العلوم الشرعية

## المتطلبات
- Node.js 20 أو أحدث.
- PostgreSQL (يفضل خدمة مُدارة).
- حساب LiveKit Cloud ومشروع LiveKit.
- استضافة Node.js مثل Render.

## تجهيز قاعدة البيانات
نفّذ محتوى `server/sql/schema.sql` مرة واحدة على قاعدة PostgreSQL.

## إعداد متغيرات الخادم
انسخ `server/.env.example` إلى `server/.env` محليًا، وأدخل القيم الحقيقية. لا ترفع ملف `.env` إلى GitHub.

على Render أضف المتغيرات التالية في Environment:
`DATABASE_URL`, `DATABASE_SSL`, `JWT_SECRET`, `JWT_EXPIRES_IN`, `CORS_ORIGINS`, `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`.

`JWT_SECRET` يجب أن يكون عشوائيًا بطول 32 حرفًا على الأقل. لا تشاركه في المحادثة ولا تضعه في ملفات الواجهة.

## تشغيل الخادم محليًا
```bash
cd server
npm install
npm start
```
اختبار الصحة:
`GET /health`

## إنشاء حساب الإدارة الأول
ضع مؤقتًا المتغيرات `BOOTSTRAP_ADMIN_NAME`, `BOOTSTRAP_ADMIN_EMAIL`, `BOOTSTRAP_ADMIN_PASSWORD` في بيئة الخادم/الطرفية، ثم:
```bash
cd server
npm run admin:create
```
كلمة المرور يجب أن تكون 16 حرفًا على الأقل. بعد إنشاء الحساب، احذف متغيرات BOOTSTRAP من بيئة النشر. لا ترسل كلمة المرور في المحادثة.

## واجهات API الأساسية
- `POST /api/auth/login` — دخول.
- `GET /api/me` — بيانات الحساب الحالي.
- `GET /api/rooms` — الحلقات المخصصة للحساب.
- `POST /api/admin/users` — إنشاء محاضر/طالب وتخصيص الحلقات (مدير فقط).
- `POST /api/teacher/rooms/:roomKey/start` — بدء الحلقة (محاضر مخصص أو مدير).
- `POST /api/live/token` — رمز دخول LiveKit بعد التحقق من الحساب والحلقة.
- `POST /api/teacher/rooms/:roomKey/mute` — كتم مشارك (محاضر مخصص أو مدير).

كل الطلبات المحمية تستخدم:
`Authorization: Bearer <token>`

## النشر على Render
أنشئ Web Service من مستودع GitHub:
- Root Directory: `server`
- Build Command: `npm install`
- Start Command: `npm start`

أضف قاعدة PostgreSQL منفصلة، ثم نفّذ `schema.sql` عليها. أضف متغيرات البيئة المطلوبة في Render. اضبط `CORS_ORIGINS` على رابط GitHub Pages الفعلي للموقع، بدون `/` في النهاية.

## تنبيه مهم عن حالة التنفيذ
هذه الحزمة هي **نواة Backend أولية** وليست منصة مكتملة بعد. لم يتم بعد:
1. دمج شاشة تسجيل الدخول ولوحات المحاضر/الإدارة في واجهة الموقع.
2. إضافة واجهة WebRTC/LiveKit في المتصفح (الكاميرا والميكروفون والفيديو ومشاركة الشاشة ورفع اليد والدردشة).
3. بناء واجهة إدارة مرئية لإنشاء الحسابات وتوزيع الطلاب.
4. اختبار عملي على Render/LiveKit أو اختبار حمل حقيقي لـ30 مشاركًا.

لا تضع بيانات حقيقية أو تعتمد على المنصة للتدريس قبل إكمال هذه المراحل والاختبارات الأمنية والتشغيلية.


## واجهة الدخول والفصل المباشر — portal.html
أُضيفت صفحة `portal.html` وربطت من الصفحة الرئيسية. عدّلي ثابت `API_BASE` داخلها إلى عنوان Render الحقيقي بعد النشر، ثم ارفعي ملفات الموقع إلى GitHub Pages.

الصفحة تدعم:
- تسجيل الدخول وإظهار الحلقات المخصصة للحساب.
- المحاضر يبدأ الحلقة، والطالب يدخل الحلقة المخصصة له فقط.
- اتصال LiveKit، وعرض مسارات الفيديو التي تصل للمتصفح.
- المحادثة ورفع اليد عبر بيانات LiveKit.
- تشغيل كاميرا/ميكروفون المحاضر ومشاركة شاشته.
- الطالب يبدأ بدون صلاحية نشر الصوت/الفيديو؛ أضيف مسار موافقة خادمي لتمكين النشر بعد موافقة المحاضر.

ملاحظة: واجهة زر موافقة المحاضر وإدارة المشاركين/الكتم التفصيلي ما زالت تحتاج استكمالًا في المرحلة التالية. زر الميكروفون لدى الطالب لا يفتح تلقائيًا قبل بناء واجهة موافقة المحاضر وربطها بالمسار `/api/teacher/rooms/:roomKey/approve/:identity`. لا تعتبري هذه النسخة جاهزة للتشغيل الفعلي قبل ضبط عنوان API وبيانات الخدمات وإجراء اختبار تكاملي.


## تحديث الهوية البصرية
تم توحيد الصفحة الرئيسية وبوابة دخول الفصول على الهوية البيضاء مع الكحلي والذهبي، بالاستناد إلى ملف التصميم المرجعي المرفق. لم يتم تغيير واجهات API أو إعدادات الخادم أو صلاحيات المستخدمين في هذا التحديث.
